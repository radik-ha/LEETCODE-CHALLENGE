## **106. Construct Binary Tree from Inorder and Postorder Traversal**



Given two integer arrays inorder and postorder where inorder is the inorder traversal of a binary tree and postorder is the postorder traversal of the same tree, construct and return the binary tree.



&#x20;



Example 1:





Input: inorder = \[9,3,15,20,7], postorder = \[9,15,7,20,3]

Output: \[3,9,20,null,null,15,7]

Example 2:



Input: inorder = \[-1], postorder = \[-1]

Output: \[-1]

&#x20;



Constraints:



1 <= inorder.length <= 3000

postorder.length == inorder.length

\-3000 <= inorder\[i], postorder\[i] <= 3000

inorder and postorder consist of unique values.

Each value of postorder also appears in inorder.

inorder is guaranteed to be the inorder traversal of the tree.

postorder is guaranteed to be the postorder traversal of the tree.



**Solution:**



/\*\*

&#x20;\* Definition for a binary tree node.

&#x20;\* public class TreeNode {

&#x20;\*     int val;

&#x20;\*     TreeNode left;

&#x20;\*     TreeNode right;

&#x20;\*     TreeNode() {}

&#x20;\*     TreeNode(int val) { this.val = val; }

&#x20;\*     TreeNode(int val, TreeNode left, TreeNode right) {

&#x20;\*         this.val = val;

&#x20;\*         this.left = left;

&#x20;\*         this.right = right;

&#x20;\*     }

&#x20;\* }

&#x20;\*/

class Solution {

&#x20;   int postindex;

&#x20;   public TreeNode buildTree(int\[] inorder, int\[] postorder) {

&#x20;       postindex = postorder.length-1;

&#x20;       return func(inorder,postorder,0,inorder.length-1);

&#x20;   }

&#x20;   public TreeNode func(int\[] inorder,int\[] postorder,int left,int right)

&#x20;   {

&#x20;       if(left>right)

&#x20;       {

&#x20;           return null;

&#x20;       }

&#x20;       int rootvalue = postorder\[postindex--];

&#x20;       TreeNode root = new TreeNode(rootvalue);

&#x20;       int index = 0;

&#x20;       for(int i=left;i<=right;i++)

&#x20;       {

&#x20;           if(inorder\[i] == rootvalue)

&#x20;           {

&#x20;               index = i;

&#x20;               break;

&#x20;           }

&#x20;       }

&#x20;       root.right = func(inorder,postorder,index+1,right);

&#x20;       root.left = func(inorder,postorder,left,index-1);

&#x20;       return root;

&#x20;   }

}
