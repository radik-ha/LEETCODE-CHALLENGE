## **105. Construct Binary Tree from Preorder and Inorder Traversal**



Given two integer arrays preorder and inorder where preorder is the preorder traversal of a binary tree and inorder is the inorder traversal of the same tree, construct and return the binary tree.



&#x20;



Example 1:





Input: preorder = \[3,9,20,15,7], inorder = \[9,3,15,20,7]

Output: \[3,9,20,null,null,15,7]

Example 2:



Input: preorder = \[-1], inorder = \[-1]

Output: \[-1]

&#x20;



Constraints:



1 <= preorder.length <= 3000

inorder.length == preorder.length

\-3000 <= preorder\[i], inorder\[i] <= 3000

preorder and inorder consist of unique values.

Each value of inorder also appears in preorder.

preorder is guaranteed to be the preorder traversal of the tree.

inorder is guaranteed to be the inorder traversal of the tree.



**Solution:**



/\*\*

&#x20;\* Definition for a binary tree node.

&#x20;\* public class TreeNode {

&#x20;\*     int val;

&#x20;\*     TreeNode left;

&#x20;\*     TreeNode right;

&#x20;\*     TreeNode() {}

&#x20;\*     TreeNode(int val) { this.val = val; }

&#x20;\*     TreeNode(int val, TreeNode left, TreeNode right) {

&#x20;\*         this.val = val;

&#x20;\*         this.left = left;

&#x20;\*         this.right = right;

&#x20;\*     }

&#x20;\* }

&#x20;\*/

class Solution {

&#x20;   int preindex = 0;

&#x20;   public TreeNode buildTree(int\[] preorder, int\[] inorder) {

&#x20;       return func(preorder,inorder,0,inorder.length-1);

&#x20;   }

&#x20;   public TreeNode func(int\[] preorder,int\[] inorder,int left,int right)

&#x20;   {

&#x20;       if(left>right)

&#x20;       {

&#x20;           return null;

&#x20;       }

&#x20;       int rootvalue = preorder\[preindex++];

&#x20;       TreeNode root = new TreeNode(rootvalue);

&#x20;       int index = 0;

&#x20;       for(int i=left;i<=right;i++)

&#x20;       {

&#x20;           if(inorder\[i] == rootvalue)

&#x20;           {

&#x20;               index = i;

&#x20;               break;

&#x20;           }

&#x20;       }

&#x20;       root.left = func(preorder,inorder,left,index-1);

&#x20;       root.right = func(preorder,inorder,index+1,right);

&#x20;       return root;

&#x20;   }

}
